Головна HTML та CSS JavaScript

HTML та CSS - основа вебу

HTML (HyperText Markup Language) - це стандартна мова розмітки для створення веб-сторінок. Вона описує структуру веб-документа за допомогою тегів. Перша версія HTML була розроблена Тімом Бернерсом-Лі у 1991 році, і з тих пір мова значно еволюціонувала.

Поточна версія HTML5 принесла велику кількість нових можливостей, серед яких - семантичні елементи (<header>, <footer>, <article>, <section>), елементи мультимедіа (<audio>, <video>), API для локального зберігання даних та можливості для роботи з графікою через <canvas>.

Каскадні таблиці стилів CSS

CSS (Cascading Style Sheets) - це мова стилів, що описує зовнішній вигляд HTML-документа. Завдяки CSS розробники можуть відокремити оформлення від змісту сторінки, що значно спрощує підтримку та розвиток веб-ресурсів.

Три способи підключення CSS до HTML-документа: вбудовані стилі (атрибут style), внутрішні стилі (тег <style> у секції <head>) та зовнішні стилі (підключення через тег <link>). Зовнішні стилі є найбільш ефективним підходом при розробці багатосторінкових веб-сайтів.

CSS3 та сучасні можливості

CSS3 розширив можливості стилів, додавши підтримку анімацій, переходів, тіней, заокруглених кутів та градієнтів. Також з'явились потужні інструменти для розмітки: Flexbox і CSS Grid, що значно спростили створення адаптивних макетів.

Медіа-запити (@media) дозволяють застосовувати різні стилі залежно від розміру екрана пристрою, що є основою адаптивного (responsive) дизайну. Це дозволяє одному веб-сайту однаково добре відображатися і на смартфоні, і на великому моніторі.
