Лабораторна робота №8 — Завдання 2: Глобальні таблиці стилів

Розділ 1: Мови розмітки

HTML розшифровується як HyperText Markup Language і є основою будь-якої веб-сторінки. За допомогою тегів описують що де знаходиться на сторінці — заголовки, абзаци, картинки, таблиці. Браузер зчитує ці теги і відображає сторінку у зрозумілому вигляді.

HTML не є мовою програмування — він лише описує структуру. Щоб сторінка виглядала гарно потрібен ще й CSS. А щоб вона реагувала на дії — підключають JavaScript. Разом ці три технології дають повноцінну веб-сторінку.

Версії HTML по роках:
HTML 1.0 (1991) — HTML 2.0 (1995) — HTML 3.2 (1997) — HTML 4.01 (1999) — HTML5 (2014) — зараз підтримується як Living Standard організацією WHATWG.

Розділ 2: Каскадні таблиці стилів

CSS (Cascading Style Sheets) — це мова для оформлення HTML-документів. Завдяки їй можна задавати кольори, шрифти, розміри і розташування елементів. Слово «каскадні» означає що стилі можуть накладатись один на одного з певними пріоритетами.

Є три способи підключити CSS до сторінки: прямо в тегу через атрибут style, у блоці <style> в шапці документа, або в окремому файлі через <link>. Третій спосіб найзручніший коли стиль треба застосувати до багатьох сторінок одразу.

Переваги CSS: відокремлює зовнішній вигляд від змісту, зменшує дублювання коду, дозволяє змінити дизайн усього сайту редагуванням одного файлу.
