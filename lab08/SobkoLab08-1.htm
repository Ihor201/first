Лабораторна робота №8 — Завдання 1: Стилі шрифтів та тексту

Веб-програмування — це створення сайтів і програм для інтернету. Для цього вивчають HTML, CSS і JavaScript. HTML описує що є на сторінці, CSS — як це виглядає, а JS додає різні ефекти і реакцію на дії користувача.

мова гіпертекстової розмітки (html) — це основа будь-якої сторінки. з її допомогою задають заголовки, абзаци, посилання та картинки. браузер читає теги і показує готову сторінку.

CSS — це таблиці стилів для HTML-документів. З їх допомогою налаштовують кольори, шрифти і відступи. Завдяки CSS можна змінювати зовнішній вигляд усієї сторінки з одного місця.

Цей абзац показує перекреслений текст зеленого кольору по правому краю. Перекреслення задається через text-decoration: line-through у властивостях CSS.

JavaScript дозволяє зробити сторінку живою — кнопки, форми, анімації. Він виконується прямо у браузері і може змінювати html без перезавантаження. Також js використовують на сервері завдяки платформі node.js.

Щоб стати веб-розробником треба знати як мінімум три технології — HTML, CSS і JS. Крім цього зараз активно використовують різні фреймворки, наприклад React або Vue. Вони спрощують написання коду і прискорюють розробку.
