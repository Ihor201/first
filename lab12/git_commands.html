Довідник команд Git

Основні команди системи контролю версій Git | Лаб. робота №12 | Собко І.О.

Налаштування Git

КомандаОпис
git config --global user.name "Name"Встановити ім'я користувача
git config --global user.email "email"Встановити email користувача
git config --listПереглянути всі налаштування
git config --global core.editor "code"Встановити редактор за замовчуванням

Ініціалізація та клонування

КомандаОпис
git initІніціалізувати новий репозиторій у поточній папці
git clone <url>Клонувати репозиторій за URL
git clone <url> <dir>Клонувати у конкретну папку

Базові команди (знімки / commits)

КомандаОпис
git statusПоказати стан робочого каталогу
git add <file>Додати файл до індексу (staging area)
git add .Додати всі змінені файли до індексу
git commit -m "message"Зберегти зміни з повідомленням
git commit -am "message"Додати всі відстежувані файли та зробити коміт
git diffПоказати незіндексовані зміни
git diff --stagedПоказати зіндексовані (staged) зміни
git rm <file>Видалити файл з репозиторію та диску
git mv <old> <new>Перейменувати або перемістити файл

Гілки (Branches)

КомандаОпис
git branchПоказати всі локальні гілки
git branch -aПоказати всі гілки (локальні + віддалені)
git branch <name>Створити нову гілку
git checkout <name>Переключитись на гілку
git checkout -b <name>Створити та переключитись на нову гілку
git switch <name>Переключитись на гілку (сучасний спосіб)
git switch -c <name>Створити та переключитись (сучасний спосіб)
git merge <branch>Злити гілку у поточну
git branch -d <name>Видалити гілку (після злиття)
git branch -D <name>Видалити гілку примусово

Робота з віддаленим репозиторієм

КомандаОпис
git remote -vПоказати підключені віддалені репозиторії
git remote add origin <url>Підключити віддалений репозиторій
git push origin <branch>Відправити зміни на сервер
git push -u origin <branch>Відправити та встановити upstream
git pullЗавантажити та злити зміни з сервера
git fetchЗавантажити зміни без злиття
git push --allВідправити всі гілки на сервер

Перегляд історії

КомандаОпис
git logПоказати журнал комітів
git log --onelineКоротка форма журналу (1 рядок = 1 коміт)
git log --graph --allГраф гілок у консолі
git show <hash>Показати деталі конкретного коміту
git blame <file>Хто і коли змінював кожен рядок файлу

Скасування та відновлення

КомандаОпис
git restore <file>Скасувати зміни у файлі (не зіндексовані)
git restore --staged <file>Прибрати файл зі staged area
git revert <hash>Скасувати коміт новим комітом (безпечно)
git reset --soft HEAD~1Відмінити останній коміт, зберегти зміни
git reset --hard HEAD~1Відмінити останній коміт і зміни (обережно!)
git stashТимчасово зберегти незакінчені зміни
git stash popВідновити збережені зміни
git stash listПоказати список збережених станів
