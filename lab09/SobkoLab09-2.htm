Лабораторна робота №9 — Завдання 2: Вільні стильові класи

Розділ 1. Мова HTML

HTML — це мова розмітки яку використовують для створення веб-сторінок. За допомогою тегів описують структуру документа: де заголовок, де абзац, де посилання. Браузер зчитує ці теги і відображає готову сторінку.

У версії HTML5 з'явилися нові теги — header, footer, article, section. Вони допомагають краще описати структуру сторінки і полегшують роботу пошуковикам при індексації сайту.

Примітка: HTML винайшов Тім Бернерс-Лі у 1991 році. Зараз стандарт підтримується організацією WHATWG як Living Standard.
Розділ 2. Таблиці стилів CSS

CSS відповідає за те як виглядає HTML-сторінка — кольори, шрифти, відступи. Завдяки CSS можна відокремити зміст від оформлення, що дуже зручно при розробці. Один файл стилів може застосовуватись до багатьох сторінок одразу.

Слово «каскадні» у назві означає що стилі можуть перекривати один одного. Якщо до одного елемента підходять кілька правил — спрацює те яке має вищу специфічність або стоїть пізніше в коді.

Примітка: CSS3 — це не одна специфікація, а набір окремих модулів. Кожен модуль (кольори, flexbox, анімації) розробляється окремо консорціумом W3C.
Розділ 3. JavaScript

JavaScript — мова яка виконується прямо в браузері і робить сторінку живою. Можна змінювати вміст, реагувати на кліки, відправляти запити на сервер. Це єдина мова яку підтримують всі браузери без додаткових плагінів.

Завдяки Node.js JavaScript тепер можна використовувати і на сервері. Це дозволяє писати весь проект однією мовою — і клієнт і сервер. Дуже зручно для великих команд розробників.

Примітка: JavaScript назвали так з маркетингових причин у 1995 році коли Java була дуже популярна. Насправді ці дві мови не пов'язані між собою.
Розділ 4. Фреймворки та бібліотеки

Щоб не писати все з нуля розробники використовують фреймворки. React від Facebook — популярна бібліотека для побудови інтерфейсів. Vue.js легше вивчити, Angular підходить для великих корпоративних проектів.

Примітка: За даними опитування Stack Overflow, React — найпопулярніший фреймворк серед веб-розробників вже кілька років поспіль.
