Лабораторна робота №9 — Завдання 1: Класи для заголовків H2

Три різних класи для <h2>, кожен використовується по кілька разів.

Комп'ютерні мережі

Комп'ютерна мережа — це коли кілька комп'ютерів з'єднані між собою щоб обмінюватись даними. Мережі бувають локальні (LAN) — наприклад у школі чи офісі, і глобальні (WAN) — як інтернет. Пристрої з'єднують через кабель або бездротово через Wi-Fi.

Операційні системи

Операційна система керує всіма ресурсами комп'ютера — процесором, пам'яттю, пристроями. Без неї програми просто не запустяться. Найпоширеніші ОС — Windows, macOS і Linux. Кожна має свої переваги і підходить для різних задач.

Бази даних

База даних — це місце де зберігаються структуровані дані. Щоб працювати з ними використовують СУБД: MySQL, PostgreSQL, SQLite. Запити пишуть на мові SQL — з її допомогою можна вибирати, додавати і змінювати записи.

Веб-технології

Основа веб-розробки — HTML, CSS і JavaScript. HTML задає структуру, CSS оформлення, JS логіку. На сервері пишуть на PHP, Python або Node.js. Для зручності використовують фреймворки типу React, Angular чи Vue.

Алгоритми та структури даних

Алгоритм — це чітка послідовність дій для розв'язання якоїсь задачі. Основні структури даних: масиви, списки, стеки, черги, дерева. Вміння їх застосовувати дуже важливе для написання ефективного коду.

Програмування на Python

Python — зручна мова з простим синтаксисом. Добре підходить для початківців. Активно використовується в аналізі даних, машинному навчанні і веб-розробці. Популярні бібліотеки: NumPy, Pandas, Flask, TensorFlow.

Кібербезпека

Кібербезпека вивчає методи захисту комп'ютерів і даних від атак. Це дуже актуальна тема — зломи і витоки даних трапляються постійно. Спеціалісти в цій галузі добре заробляють і їх постійно не вистачає на ринку.
